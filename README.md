OpenTelemetry를 이용한 계측, 이벤트·추적 기반 디버깅, SLO 기반 알람, 대규모 환경에서의 스토리지·샘플링·파이프라인,
그리고 조직에 관찰 가능성 문화를 확산하는 방법까지 다루는 책입니다.

## ✍️ 진행 방식

PART마다 담당자가 정해져 있습니다.

1. 담당자는 맡은 PART를 읽고 해당 폴더에 MD 파일로 정리합니다.
2. 모임에서 정리한 내용을 공유하고, 이해 안 된 부분과 토론 주제를 함께 다룹니다.
3. 모임이 끝나면 담당자가 논의 결과와 액션 아이템을 문서에 덧붙입니다.

### 폴더 구조

```
.
├── README.md
├── TEMPLATE.md        # 정리 문서 양식
├── PART1/
│   ├── README.md      # PART 소개 · chapter 목록
│   └── *.md           # 담당자가 작성하는 정리 문서
├── PART2/
├── PART3/
├── PART4/
└── PART5/
```

### 정리 문서

- 맡은 `PARTn/` 폴더 안에 MD 파일로 작성합니다. 파일명과 파일 개수는 자유입니다.
- 양식은 [TEMPLATE.md](./TEMPLATE.md)를 복사해서 씁니다.

| 템플릿 항목 | 쓰는 내용 |
| --- | --- |
| 세 문장 요약 | PART 전체를 세 문장 이내로 |
| 핵심 용어 | 책의 정의와 내 말로 다시 쓴 정의 |
| chapter별 정리 | 저자의 주장 · 근거와 예시 · 인상 깊은 문장 · 내 생각 |
| 이해 안 된 부분 | 쪽수와 함께 최소 3개 |
| 토론 주제 | 정답이 하나로 정해지지 않는 질문 |
| LMS 프로젝트에 적용한다면 | 지금 상태 · 책의 제안 · 해볼 수 있는 것 |
| 모임 기록 | 논의 결과 · 남은 질문 · 액션 아이템 (모임 후 작성) |
| 더 읽을거리 | 관련 글과 문서 링크 |

### 커밋 규칙

```
[PART1] 조상근 - chapter 1~4 정리
```

- 맡은 PART 폴더만 수정하면 충돌이 나지 않습니다.
- 다른 PART 문서에 대한 의견은 Issue나 PR 코멘트로 남깁니다.
