관찰 가능성(Observability)이 무엇이고 왜 필요한지, 기존 모니터링과 무엇이 다른지에서 출발해
OpenTelemetry를 이용한 계측, 이벤트·추적 기반 디버깅, SLO 기반 알람, 대규모 환경에서의 스토리지·샘플링·파이프라인,
그리고 조직에 관찰 가능성 문화를 확산하는 방법까지 다루는 책입니다.

## ✍️ 진행 방식

1. 해당 주차의 PART를 읽습니다.
2. 각자 그 PART 폴더 안에 본인 MD 파일을 작성합니다.
3. 모임에서 정리한 내용과 질문을 공유합니다.

### 폴더 구조

```
.
├── README.md
├── TEMPLATE.md        # 정리 문서 양식
├── PART1/
│   ├── README.md      # PART 소개 · chapter 목록
│   └── 이름.md         # 각자 작성
├── PART2/
├── PART3/
├── PART4/
└── PART5/
```

### 파일 규칙

- 위치: `PARTn/` 폴더 바로 아래
- 파일명: `이름.md` (예: `PART1/조상근.md`)
  - chapter별로 나눠 쓰고 싶다면 `이름_ch01.md` 형식
- 양식: [TEMPLATE.md](./TEMPLATE.md)를 복사해서 사용 (형식은 자유롭게 바꿔도 됩니다)
- 이미지: `PARTn/images/` 아래에 두고 상대 경로로 참조

### 커밋 규칙

```
[PART1] 조상근 - chapter 1~4 정리
```

- 본인 파일만 수정하면 충돌이 나지 않습니다.
- 다른 사람 문서에 대한 의견은 Issue나 PR 코멘트로 남깁니다.
